## 👋 About

We are a group of **42 Luxembourg** students building open-source tools to make the 42 curriculum easier, faster, and more fun. Our projects are built by students, for students — free and open source.

> *"The best way to learn is to build things that help others learn."*

## 🚀 Featured Project

<div align="center">

### [libft-ghost 👻](https://github.com/42staverni/libft-ghost)

**The ultimate web-based libft tester for 42 School students**

[![Docker Pulls](https://img.shields.io/badge/docker-ghcr.io%2F42staverni%2Flibft--ghost-0db7ed?style=flat-square&logo=docker&logoColor=white)](https://ghcr.io/42staverni/libft-ghost)
[![Language](https://img.shields.io/badge/Go-00ADD8?style=flat-square&logo=go&logoColor=white)](https://github.com/42staverni/libft-ghost)
[![Language](https://img.shields.io/badge/Svelte-FF3E00?style=flat-square&logo=svelte&logoColor=white)](https://github.com/42staverni/libft-ghost)
[![Language](https://img.shields.io/badge/C-A8B9CC?style=flat-square&logo=c&logoColor=black)](https://github.com/42staverni/libft-ghost)

</div>

Drop your `libft` folder in the browser and get instant test results — no local setup required. A single Docker command and you're testing in seconds.

| Feature | Description |
|---|---|
| 🔍 **Norminette** | Built-in 42 style checker |
| 🧠 **Memory Leaks** | Valgrind integration |
| 💥 **Buffer Overflows** | AddressSanitizer (ASan) |
| ⚡ **Fast Mode** | Skip memory checks for rapid iteration |
| 🌓 **Dark / Light UI** | Glassmorphism design |
| 🐳 **One command** | `docker run -p 5173:5173 ghcr.io/42staverni/libft-ghost:latest` |
